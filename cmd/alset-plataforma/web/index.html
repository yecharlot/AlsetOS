Qué hacer: rellena empresa y procesos → pulsa Generar informe + ORGES → mira el panel Resultado (derecha) y el editor .aos abajo.

Pega un CREATE TABLE, JSON de esquema o notas de API REST. Luego genera draft ORGES.

Finanzas → ORGES

JSON/CSV/PDF o ejemplo. Ratios + draft .aos.
