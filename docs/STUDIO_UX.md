# Alset Studio — UX y paneles

## Vistas

| Pestaña | Uso |
|---------|-----|
| **Arquitecto** | Modos 1–5, entrevista, resultado, finanzas, tokenizar |
| **Editor · Preview · Deploy** | Toolbox, editor `.aos`, preview, consola, deploy |

Modo **4 · Implementación** abre automáticamente la pestaña Editor.

## Paneles (vista Editor)

| Panel | Cerrar | Redimensionar |
|-------|--------|----------------|
| Toolbox (izq.) | × o toggle **Toolbox** | splitter vertical |
| Propiedades (der.) | × o toggle **Propiedades** | splitter vertical |
| Consola | × o toggle **Consola** | cabecera / splitter |
| Preview | × o toggle **Preview** | cabecera / splitter |

En pantallas < 860px los laterales empiezan cerrados; ábrelos con los toggles de la barra superior.

## Flujo

1. Arquitecto → datos → **Generar informe + ORGES**
2. Editor → **Aplicar flow** → **Correr preview** → **Desplegar producción**
