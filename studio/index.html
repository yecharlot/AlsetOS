Ayuda · Alset Studio ORGES

Objetivo: definir organismos (ORGES) en LISPAI-AOS, unirlos como LEGO, probarlos y desplegarlos listos para producción.

  1. Arrastra componentes del Toolbox al canvas o edita el .aos.
  2. Aplicar flow carga el runtime (contratos, estado, reglas).
  3. Correr preview monta la UI-orge; los botones ejecutan acciones reales (stock.inc, venta.registrar…).
  4. Probar ejecuta los (test …) del flow.
  5. Desplegar producción escribe /apps/<nombre>/ servida por este Studio (PWA lista).

Emits con funcionalidad real

  • stock.inc / stock.dec — suman/restan stock.unidades
  • venta.registrar — descuenta stock y marca venta
  • campo=valor — escribe átomo de estado
