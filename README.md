# AlsetOS

Primera prueba ejecutable del núcleo conceptual de AlsetOS.

## Flujo

`Organismo → RootCID → LispAI → Zyrion → Mind → Gene → Pulso → resultado`

## Ejecutar

```bash
go run ./cmd/alsetos
```

El código de esta primera versión usa exclusivamente la biblioteca estándar de Go y mantiene los nombres de dominio, variables y estructuras en español.

La implementación es deliberadamente mínima: prueba el contrato semántico antes de introducir red P2P, WASM, persistencia distribuida o el intérprete LispAI completo.
